# La tabla RDM1

Estas son las especificaciones de la tabla RDM1

Radial Metric
Sep 22, 2010

Radial Metric is a new optional output feature funded via U.S. IOOS by NOAA through a contract from Scripps Institution of Oceanography.

Radial Metric is built into SeaSonde Radial Suite Release 7. The Radial Metric files are low-level conversions of single cross spectra using MUSIC processing into one or two radial vectors per doppler cell. The single angle and dual angle bearings are available in the output as well as all the dual angle decision-making ratios, MUSIC processing values, and the spectra power levels.

The purpose of the radial metric is to give researchers the ability to look deeper into the SeaSonde Radial Processing. Turning on the Radial Metric will produce a lot more data and will slow down radial processing.

To turn on/off Radial Metric, change configuration file AnalysisOptions.txt Line 21 Parameter 1.

Set to 0 to disable.

Set to 1 to enable radial metric and normal short-time radial output.

Set to 2 to just output radial metric.

Set to 3 to output radial metric across all doppler points within the configuration maximum velocity. Points outside of the first order boundary are flagged with +32.

The Radial Metric file is a LLUV variation which can be plotted with SeaDisplay. There are one or two LLUV vectors for each spectra range, doppler cell processed. A single vector from a range and doppler cell is a MUSIC single angle solution. Two vectors with same range and doppler cells are created for a MUSIC dual angle solution. There is a column which indicates which bearing was selected (1 = single, 2 = dual angle1, 3 = dual angle2). The LLUV & RBVD columns describe the bearing selected by Radial processing. The rest of the columns describe the spectra and MUSIC calculations which is duplicated on two lines when the solution is a dual angle; this can make the file twice as large as really needed but keeps the file LLUV compatible and displayable in SeaDisplay.

Data Column Types:

LOND LATD are the standard longitude,latitude location.
VELU VELV are the standard u,v easting,northing velocity components.
RNGE BEAR VELO HEAD are the standard range,bearing,velocity,heading for vector.

VFLG column indicates the validity of the vector. This value is a composite sum of powers of 2 (think binary) where each power of 2 sum is a different indicator.
! (SeaDisplay version 10.4.10 and later will not plot vectors that have these flags set.)

Possible flags are:
! +32 (bit5) indicates that vector was beyond the config maximum current (This will not happen in typically metric files.)
! +64 (bit6) indicates vector was rejected due to low signal to noise (either on low Antenna 3 and/or (low Antenna 1 and Antenna 2).
! +128 (bit7) indicates vector is out of angular limit bounds. (Doesnʼt occur in normal metric output but can happen if reprocessed with RadialFromMetric tool.)
! +1024 (bit10) indicates vector was rejected due to ionospheric noise check for range cell & Bragg.

SPRC is the spectra range cell (from 0 which is at site)
SPDC is the spectra doppler index (from 0 left side/maximum negative Bragg.)

MSEL is the MUSIC bearing selected (1=single, 2=dual angle1, 3=dual angle2)

MSA1 is MUSIC single angle bearing. (1440 if invalid)
MDA1 is MUSIC dual angle first bearing (1440 if invalid)
MDA2 is MUSIC dual angle second bearing (1440 if invalid)
MEGR is MUSIC eigen ratio of first to second.
MPKR is MUSIC dual angle power signal ratio of first to second.
MDFR is MUSIC dual angle off diagonal ratio.
MSP1 is MUSIC Single angle power in dB (10*log10)

MDP1 is MUSIC Dual angle first power in dB
MDP2 is MUSIC Dual angle second power in dB
MSW1 is MUSIC Single angle antenna response angular width of the 3dB down from response peak bearing.
MDW1 is MUSIC Dual first angle antenna response angular width of the 3dB down from response peak bearing.
MDW2 is MUSIC Dual second angle antenna response angular width of the 3dB down from response peak bearing.
MSR1 is the MUSIC Single angle antenna response peak value
MDR1 is the MUSIC Dual first angle antenna response peak value
MDR2 is the MUSIC Dual second angle antenna response peak value
MA1S is the spectra antenna Loop1 signal to noise in dB
MA2S is the spectra antenna Loop2 signal to noise in dB
MA3S is the spectra antenna monopole signal to noise in dB
MEI1 is the MUSIC first eigen value
MEI2 is the MUSIC second eigen value
MEI3 is the MUSIC third eigen value

MDRJ is the MUSIC dual angle rejection reason(s). This value is a composite sum of powers of 2 (think binary) where each power of 2 sum is a different indicator. Possible flags are

If 0, then solution is OK to be dual angle.

+1 failed eigen ratio check.

+2 failed signal ratio check.

+4 failed off diagonal ratio check.

+8 failed MDA1 is too close to MDA2

+16 only one dual angle bearing solution found. The other possible angle did not have a peak MUSIC response.

RadialFromMetric Tool:

Converts radial metrics to short-time radial outputs; separate instructions are available.
